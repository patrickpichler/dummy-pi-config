# dummy-pi-config

A [pi](https://github.com/badlogic/pi-mono) package containing a 🎰 slot machine extension.

## Install

```bash
# from git
pi install git:github.com/patrickpichler/dummy-pi-config

# or from a local checkout
pi install ./dummy-pi-config
```

## Usage

Start pi and run `/slots`. Spin the reels while the AI thinks —
credits persist across sessions.

- `SPACE` spin
- `+` / `-` change bet
- `P` paytable
- `R` refill credits (when broke)
- `Q` quit
